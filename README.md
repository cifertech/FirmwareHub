### A browser-based firmware flasher

Flash and manage firmware for CiferTech devices, no software install, just Chrome or Edge.

## ✨ Features

- One-click `.bin` flashing via WebSerial — no drivers or software
- Pulls firmware directly from GitHub Releases (auto-fetch, OTA URLs)
- Live device info: chip family, flash size, MAC address
- Built-in serial console + local flash history
- Drag-and-drop UI with CiferTech dark theme

## 🔧 Usage

1. Open the [web app](https://cifertech.github.io/FirmwareHub/)
2. Connect your board via USB
3. Load a local `.bin` or pick a GitHub release
4. Hit **Flash**

> ⚠️ Requires Chrome or Edge — WebSerial needs HTTPS when hosted online.
